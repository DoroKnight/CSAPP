-------------------------------------------------------------------------------
1. 构建 Y86-64 工具
-------------------------------------------------------------------------------

Y86-64 模拟器可以配置为支持 TTY 和 GUI 两种界面。在 TTY 模式下运行的
模拟器会在终端中输出其运行时行为的全部信息。这种方式较难直观地理解
模拟器内部正在发生什么，但适用于自动化测试，并且不需要安装任何特殊
组件。在 GUI 模式下运行的模拟器使用功能丰富的图形用户界面，适合进行
可视化观察和调试，但要求系统已经安装 Tcl/Tk。

若要构建 Y86-64 工具，请执行以下步骤：

注意：如果该发行版已经由你的教师预先配置，那么可以跳过步骤 1，直接
执行步骤 2。此时 Makefile 中的 GUIMODE、TKLIBS 和 TKINC 已经设置为
适合你所使用系统的值。

步骤 1：确定要构建模拟器的 TTY 版本还是 GUI 版本，然后相应地修改
本目录中的 ./Makefile。（在该 Makefile 中对变量所做的设置，会覆盖
seq 和 pipe 目录中各自 Makefile 已经设置的值。）

构建 GUI 模拟器：如果系统已经安装 Tcl/Tk，则可以通过为 GUIMODE、
TKLIBS 和 TKINC 设置适合当前系统的值来构建 GUI 版本。（默认值适用于
Linux 系统。）

设置 GUIMODE=-DHAS_GUI 会使模拟器源代码中必要的 GUI 支持代码参与
编译。TKLIBS 变量用于告诉 gcc 到哪里查找 libtcl.so 和 libtk.so 库；
TKINC 变量用于告诉 gcc 到哪里查找 tcl.h 和 tk.h 头文件。

构建 TTY 模拟器：如果系统中没有安装 Tcl/Tk，则可以在 Makefile 中
注释掉 GUIMODE、TKLIBS 和 TKINC 这三个变量，从而构建 TTY 版本。

步骤 2：将 Makefile 修改为构建 GUI 或 TTY 版本后，可以输入以下命令
构建整套 Y86-64 工具：

```go
unix> make clean; make
```

-------------------------------------------------------------------------------
2. 文件
-------------------------------------------------------------------------------

Makefile
        用于构建 Y86-64 工具。

README
        本文件。

misc/
        包含 Y86-64 汇编器 yas、Y86-64 指令模拟器 yis，以及处理器
        模拟器通过 -t 选项对照 ISA 模拟结果时使用的 isa.c 源文件。
        此外还包含 hcl2c 和 hcl2v 程序的相关文件。

seq/
        包含 SEQ 和 SEQ+ 模拟器的代码，以及用于修改 SEQ 的实验和
        作业所需的 HCL 文件。

pipe/
        包含 PIPE 模拟器的代码，以及用于修改 PIPE 的实验和作业所需
        的 HCL 文件。

y86-code/
        包含《深入理解计算机系统》（CS:APP）中的 .ys 示例文件，以及
        对新处理器设计进行自动化基准测试的脚本。

ptest/
        包含用于测试处理器设计的自动化回归测试脚本。

verilog/
        用于根据 HCL 生成 Verilog 设计的系统。
